# P07 Golden Scenario Simulation

Status: PASS

Simulated scenario families include: genuine obscure breakthrough; fake viral launch; single press release syndicated widely; independent technical confirmation; embargo/backdated release; future timestamp; real single-source zero-day; false zero-day; GitHub bot-star attack; real developer breakout; crypto reflexive pump; protocol fundamental + market response; core source outage; partial source failure; active-enrichment loop; historical backfill; correction; retraction; old-topic reacceleration; old-news resurfacing; source deletion; uncertain entity aliases; cluster split/merge; event during degraded coverage; outage backlog burst; partial snapshot failure; duplicate job; LLM hallucination; FRONTIER self-influence.

Semantic repairs accepted:
R1 NOW means consequential current developments, not merely high confirmation. High-consequence low-confirmation items may enter NOW with explicit uncertainty.
R2 SourceHealth is multidimensional: transport, freshness, completeness, schema validity.
R3 Active enrichment needs causal metadata (`triggered_by`/equivalent), not only a collection-reason label.
R4 Assertion state and trend state are orthogonal; retraction may coexist with high attention/trend activity.
R5 `NOISE` is removed from trend lifecycle; it is an assessment, not a temporal phase.
R6 `CORROBORATED` is removed from assertion lifecycle; corroboration belongs to evidence/cluster confirmation.

Canonical separation after P07:
Assertion lifecycle: OBSERVED, CORRECTED, RETRACTED.
Trend trajectory: EMERGING, RISING, BREAKOUT, MATURE, COOLING.
Signal dimensions: emergence, confirmation, confidence, coverage, manipulation/reflexivity, freshness.

No scenario required reopening the modular-monolith/Postgres/Python/React architecture.
