# P02 Mission and Operator Task Model

Status: PASS

Primary operator: technically literate, time-constrained person maintaining awareness across fast-moving technology/research/market domains without monitoring dozens of feeds.

Stable questions:
1. What happened since I last looked?
2. What strange thing is beginning to move?
3. What is becoming genuinely established?
4. Why is this moving?
5. Where did it appear to originate?
6. Are these independent confirmations or copies of one origin?
7. How certain should I be?
8. What evidence may FRONTIER be missing?
9. How did this evolve?
10. Can I inspect the original evidence myself?

Situation-awareness mapping:
- PERCEIVE: NOW/RADAR; new observations, anomalies, source/system health.
- COMPREHEND: TRENDING/DOSSIER/PROVE IT; drivers, evidence structure, confidence, coverage, manipulation/reflexivity.
- PROJECT: trajectory/history; strengthening, fading, confirmation progression without certainty theater.

Core operator decisions supported: IGNORE, WATCH, INVESTIGATE, READ PRIMARY SOURCE, COMPARE RELATED ENTITY, RETURN LATER.

P0 acceptance tasks include: find strongest new AI weak signal <=10s; determine why moving <=15s; reach primary/earliest observed evidence <=20s; determine whether visible stories are independent <=15s; detect major source degradation <=5s; reconstruct first RADAR/confirmation transition <=20s; correctly interpret high-emergence/low-confirmation as unusual but not established.

Information-density rule: optimize useful operator information divided by attention + interaction cost. Every permanent panel should answer a stable operator question.
