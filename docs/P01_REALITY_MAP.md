# P01 Reality Map

Status: PASS_WITH_CARRIED_UNKNOWNS

## Donor archaeology
- `CipherCuttle/Srcnow`: original mobile signal terminal; useful evidence-state/product-history reference. Current enterprise-oriented main is not FRONTIER authority.
- `CipherCuttle/daemonlink`: useful donor for stable source IDs, URL normalization, content hashing/dedupe, RSS plumbing, FastAPI shell and receipts. Current SRCNOW export embeds legacy channel/allowlist/quota/scoring policy and must not become FRONTIER canonical upstream.
- `CipherCuttle/Synworks---Nullstate`: conceptual donor for `Prove It`, corroboration/provenance and falsification-first doctrine.
- `CipherCuttle/Smokestack`: conceptual donor for point-in-time replay, prospective evaluation and staged authorization.

## Strong zero-paid-key source candidates
Native RSS/Atom; HN public data; GH Archive plus selective GitHub REST enrichment; arXiv; Hugging Face public Hub data; DEX Screener public endpoints; Hyperliquid public market info; Kraken public market data; Common Crawl historical backfill; GDELT discovery/corroboration; public registries such as PyPI/npm/crates; CISA KEV/OSV; SEC EDGAR; open social where policy allows.

Every production source still requires technical, policy, information-value and reliability gates.

## Hard constraints
C01 zero mandatory paid data APIs.
C02 one canonical public world state.
C03 automatic operation.
C04 evidence survives compression.
C05 broad scope: news/AI/dev/research/crypto/markets/security.
C06 professional dense terminal UX; Bloomberg-level refers to density, responsiveness and sourcing, not copying proprietary data/trade dress.
C07 no access-control circumvention.
C08 plan before implementation.

## Primary risks
R01 source rights/policy can invalidate naive 'free API' assumptions.
R02 third-party UI scraping is fragile.
R03 legacy Daemonlink WTP/pain scoring contamination.
R04 timestamp collapse causes false historical claims.
R05 aggregation can masquerade as independent corroboration.
R06 source outages can masquerade as real-world silence.
R07 migration failure must not fail open.
R08 broad GitHub discovery cannot rely on naive unauthenticated REST polling.

## Reuse
Strong: deterministic IDs/hashes, canonical URL behavior, RSS/parser substrate, source adapter concepts, receipts.
Adapt: HN role, GitHub role, evidence schema.
Reject: WTP/pain/alive scoring, Srcnow quotas/allowlists/personalized ranking, enterprise Jira/Slack workflow objective.
