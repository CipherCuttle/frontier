# FRONTIER

FRONTIER is a public, non-personalized, point-in-time intelligence terminal for emerging technology, software, research, crypto, markets, and security.

This repository is intentionally bootstrapped with a minimal `main`. Canonical product, architecture, epistemic, security, source-governance, and delivery authority is established through reviewed governance PRs before implementation.

Current rule: no product runtime implementation is authorized on `main` until PR-00 governance authority is merged.
